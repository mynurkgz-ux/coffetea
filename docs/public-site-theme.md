# Настройка темы главной страницы

Тема главной страницы общая для всех посетителей и сохраняется в Firestore. Менять её может только назначенный главный администратор сайта.

## Назначить главного администратора

1. Разверните актуальные правила Firestore:

   ```powershell
   firebase deploy --only firestore:rules --project cfteasite
   ```

2. В Firebase Console откройте **Authentication → Users** и скопируйте UID аккаунта, которому нужно дать доступ.
3. Откройте **Firestore Database → Data → profiles** и найдите документ с этим UID. Добавьте поле:
   - имя: `siteAdmin`
   - тип: boolean
   - значение: `true`
4. Откройте приложение под этим аккаунтом и зайдите в **Настройки → Тема главной сайта**. Выбранная тема сразу появится у посетителей главной страницы.

Снять доступ можно, удалив поле `siteAdmin` или установив `false`. Не выдавайте это поле владельцам кафе: оно даёт право менять оформление общей страницы сайта.

Список разрешённых значений темы проверяется правилами Firestore. Данные сайта хранятся в документе `siteSettings/publicHome`.
